# RoadMark CAD

道路標示の設計を支援するWindows用2D CADの配布専用リポジトリです。

## インストール

[最新リリース](https://github.com/phkdow/roadmark-cad-updates/releases/latest)から、`RoadMarkCAD-<バージョン>-setup.exe`をダウンロードして実行してください。Windows x64向け、ユーザー単位のインストールです。

旧ポータブル版をお使いの場合は、図面を保存して旧版を終了してからインストールしてください。通常の図面ファイルは移動・削除せず、従来の設定保存先を引き継ぎます。

## 更新

アプリの「ファイル → 更新の確認」から確認できます。ダウンロード後、保存を確認して「再起動して更新」で適用します。「あとで」は延期だけです。「アプリ終了時に更新」を選んだ場合は終了時に保存を確認します。

更新時はEd25519署名、対象バージョン・OS・CPU、ファイル名・サイズ、SHA-512を検証します。Windowsのコード署名証明書は付いていません。更新用のEd25519署名とは別の仕組みです。

## 問題が起きた場合

更新画面の「更新ログを開く」で詳細を確認できます。復旧用として前の版のインストーラーもReleasesに残します。手動で旧版へ戻す際は、図面を別名保存して保管してからアプリを終了し、旧版のインストーラーを実行してください。設定データを削除する必要はありません。

自動ロールバックはありません。ファイル形式が将来変わる更新では、その版の互換性の案内を確認してください。

## 配布ファイル

各リリースにはインストーラー、blockmap、latest.yml、署名付きマニフェストと署名を掲載します。一般の利用者が初回に実行するのはsetup.exeのみです。

このリポジトリにソースコード・秘密鍵・トークンは含みません。
