# RoadMark CAD

道路区画線の設計を支援するWindows用2D CADの配布専用リポジトリです。

## インストール

初めて入れる場合と、0.4.19以前をお使いの場合は、`RoadMarkCAD-<バージョン>-setup.exe`を実行してインストールしてください（Windows x64、ユーザー単位）。0.4.20以降は、アプリ内から更新できます。

## 更新

- アプリの「ヘルプ → 更新確認」で確認できます。起動時にも自動で確認し、新しい版があればお知らせします。
- このリポジトリの `latest.json` と `releases/<版>/` から、アプリ本体（`app.asar`）だけを取得して差し替えます（インストーラー丸ごとのダウンロードはありません）。
- 未保存の図面があるときは、更新の前に保存の確認が出ます。
- 検証：Ed25519署名、版、ファイル名、サイズ、ハッシュを確認し、合わないものは使いません。Windowsのコード署名証明書は付いていません。

## 更新に失敗した場合

- 差し替え後に新しい版が起動できない、または起動の確認が一定時間内に取れない場合は、**自動で元の版に戻し**、「更新を取り消しました」と表示します。
- 設定と図面は、更新では変更されません。
- 手動で戻す場合は、図面を保存してアプリを終了し、旧版のインストーラーを実行してください。
